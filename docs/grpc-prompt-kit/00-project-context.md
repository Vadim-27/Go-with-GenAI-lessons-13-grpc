# 00 · Контекст проєкту

> **Коли:** один раз на проєкт; оновлюйте, коли змінюються вимоги.
> **Результат:** блок тексту, який підставляється замість `{{PROJECT_CONTEXT}}` в усіх промптах набору.

Чим точніший контекст, тим менше здогадок у відповідях ШІ. Не знаєте відповіді на пункт, так і напишіть («невідомо») — ШІ тоді поставить уточнювальне питання, а не вигадає.

## Шаблон

````markdown
## Контекст проєкту

- Проєкт: {{PROJECT_NAME}}
- Предметна область: {{DOMAIN}}
- Мова та версія: {{LANGUAGE}}
- Пакет протоколу: {{PROTO_PACKAGE}}            (з версією, напр. acme.inventory.v1)
- Інструменти кодогенерації: {{TOOLCHAIN}}      (buf | protoc | інше; з версіями, якщо відомі)
- Хто викликає сервіс: {{CLIENTS}}              (внутрішні сервіси / браузер / мобільні / сторонні партнери)
- Безпека транспорту та ідентичність: {{SECURITY_MODEL}}   (mTLS / service mesh / TLS + токени / лише локально без TLS)
- Середовище виконання: {{DEPLOY_ENV}}          (Kubernetes / VM / лише локальна розробка; є балансувальник?)
- Масштаб: {{SCALE}}                            (запитів/с, типовий і максимальний розмір повідомлень, кількість клієнтів, довжина стрімів)
- Обмеження: {{CONSTRAINTS}}                    (бібліотеки, заборонене, стиль коду, сумісність зі старими клієнтами, терміни)
- Мова коментарів і документації: {{COMMENT_LANGUAGE}}

## Правила відповіді
- Якщо даних бракує — спершу постав до 5 уточнювальних питань, потім відповідай.
- Окремим списком виписуй свої припущення.
- Актуальні версії бібліотек і їхній API перевіряй за офіційною документацією, а не за пам'яттю. Якщо перевірити неможливо, познач це.
- Позначай, що ти не міг перевірити запуском.
````

## Приклад заповненого контексту

````markdown
## Контекст проєкту

- Проєкт: LibraTrack
- Предметна область: облік примірників книг у мережі бібліотек (статуси: доступний, виданий, втрачений)
- Мова та версія: Go 1.22
- Пакет протоколу: libratrack.inventory.v1
- Інструменти кодогенерації: protoc 3.21 + protoc-gen-go, protoc-gen-go-grpc, protoc-gen-grpc-gateway
- Хто викликає сервіс: внутрішні сервіси (gRPC); браузерний фронтенд (REST через gateway)
- Безпека транспорту та ідентичність: mTLS між сервісами + JWT користувача в metadata
- Середовище виконання: локальна розробка; далі Kubernetes
- Масштаб: ~500 запитів/с, повідомлення < 1 КБ, до 50 одночасних watch-стрімів
- Обмеження: без зовнішніх залежностей поза grpc, protobuf, grpc-gateway; код має компілюватись на Go 1.22
- Мова коментарів і документації: українська
````

## Короткий варіант (для швидких запитів)

````markdown
Контекст: {{PROJECT_NAME}}, {{LANGUAGE}}, пакет {{PROTO_PACKAGE}}, клієнти: {{CLIENTS}}, безпека: {{SECURITY_MODEL}}.
Бракує даних — спитай, не вгадуй. Версії бібліотек перевіряй у документації.
````
