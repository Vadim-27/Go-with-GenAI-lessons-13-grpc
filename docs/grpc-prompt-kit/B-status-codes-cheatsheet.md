# B · Коди статусу gRPC: довідник

> Використовуйте разом з [09 · Помилки й дедлайни](09-errors-and-deadlines.md). Таблиця відображає стандартну відповідність gRPC → HTTP, яку застосовує grpc-gateway; перевіряйте її для вашого gateway/проксі.

| gRPC-код | HTTP | Коли повертати | Повторювати? |
|---|---|---|---|
| `OK` (0) | 200 | Успіх | — |
| `Canceled` (1) | 499 | Клієнт скасував виклик | Ні (це рішення клієнта) |
| `Unknown` (2) | 500 | Лише коли причина справді невідома. Ознака «голої» помилки в коді | Ні |
| `InvalidArgument` (3) | 400 | Аргумент некоректний незалежно від стану системи (порожній id, поганий формат) | Ні, виправте запит |
| `DeadlineExceeded` (4) | 504 | Час вийшов (дедлайн клієнта або сервера) | Обережно: лише ідемпотентні |
| `NotFound` (5) | 404 | Сутності не існує | Ні |
| `AlreadyExists` (6) | 409 | Сутність уже є (дубль унікального ключа) | Ні |
| `PermissionDenied` (7) | 403 | Особу встановлено, прав недостатньо | Ні |
| `ResourceExhausted` (8) | 429 | Квота, ліміт швидкості, пам'ять, розмір повідомлення | Так, із затримкою |
| `FailedPrecondition` (9) | 400 | Стан системи не дозволяє операцію (видалення непорожньої теки) | Ні, поки стан не зміниться |
| `Aborted` (10) | 409 | Конфлікт конкурентності (оптимістичне блокування, транзакція) | Так, на рівні «прочитай-змін-запиши» |
| `OutOfRange` (11) | 400 | Значення поза допустимим діапазоном стану (сторінка за межами списку) | Ні |
| `Unimplemented` (12) | 501 | Метод не реалізовано або не підтримується | Ні |
| `Internal` (13) | 500 | Порушено внутрішній інваріант, баг сервера | Ні (обережно) |
| `Unavailable` (14) | 503 | Сервіс тимчасово недоступний; клієнт може повторити з backoff | **Так** |
| `DataLoss` (15) | 500 | Непоправна втрата чи пошкодження даних | Ні |
| `Unauthenticated` (16) | 401 | Немає або невалідні облікові дані | Ні, потрібен новий токен |

## Типові плутанини

- **`InvalidArgument` чи `FailedPrecondition`?** Якщо запит поганий сам по собі, `InvalidArgument`. Якщо запит нормальний, але система зараз у стані, що його не дозволяє, `FailedPrecondition`.
- **`NotFound` чи `PermissionDenied`?** Якщо наявність ресурсу сама по собі секретна, повертайте `NotFound` і для чужих ресурсів, інакше ви розкриваєте його існування.
- **`Unauthenticated` чи `PermissionDenied`?** «Хто ти?» не встановлено, `Unauthenticated`. «Ти нам відомий, але не можна», `PermissionDenied`.
- **`Unavailable` чи `Internal`?** Тимчасове, можна повторити, `Unavailable`. Баг чи зламаний інваріант, `Internal`.
- **`Aborted` чи `AlreadyExists`?** Дубль унікального ключа, `AlreadyExists`. Конфлікт паралельних змін, `Aborted`.

## Повідомлення в помилках

- Текст має бути корисним клієнту, але без внутрішніх деталей (SQL, шляхи, стек).
- Для машинної обробки додавайте деталі в `google.rpc.Status` (наприклад, `ErrorInfo`, `BadRequest` з полями, `RetryInfo` із затримкою).
- Повну причину пишіть у лог із ідентифікатором запиту, а в відповіді повертайте цей ідентифікатор.
